# House Price Prediction using Machine Learning

## Description
This project predicts house prices based on features such as square feet,
number of bedrooms, and bathrooms using Machine Learning techniques.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab

## Model Used
- Linear Regression

## Outcome
The model predicts house prices based on input features and demonstrates
a basic end-to-end machine learning workflow.
